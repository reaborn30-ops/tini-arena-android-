# Тіні Арени — Android-проєкт (початкова збірка)

Це проєкт для пакування наявного HTML-прототипу гри в Android-застосунок за допомогою Capacitor 8. У папці `www/` лежить гра, яка відкриватиметься в Android WebView.

## Найпростіший шлях отримати APK

У проєкті є GitHub Actions workflow `.github/workflows/build-apk.yml`. Після завантаження цих файлів у репозиторій GitHub збірка може автоматично створити тестовий APK.

1. Створи порожній репозиторій на GitHub, наприклад `tini-areni-android`.
2. Розпакуй ZIP і завантаж **вміст папки** в репозиторій (папку `.github` теж потрібно завантажити).
3. Відкрий вкладку **Actions** у репозиторії. Якщо GitHub попросить, дозволь запуск workflow.
4. Вибери **Build Android APK** → **Run workflow** (або дочекайся запуску після push).
5. Коли виконання завершиться успішно, відкрий його та завантаж artifact `tini-areni-debug-apk`.
6. Розпакуй завантажений artifact на телефон/комп'ютер. APK усередині називається `app-debug.apk`. Перенеси його на Android-телефон і відкрий для встановлення. Android може попросити дозволити встановлення з цього джерела.

## Збірка на комп'ютері

Потрібні Node.js 22+, Android Studio та Android SDK (API 36). В корені проєкту:

```bash
npm install
npx cap add android
npx cap sync android
npx cap open android
```

Або для debug APK після налаштування SDK:

```bash
cd android
./gradlew assembleDebug
```

Файл буде в `android/app/build/outputs/apk/debug/app-debug.apk`.

## Важливі межі поточної версії

- Це **тестовий debug APK**, а не підписаний реліз для магазину.
- Ігровий код походить із поточного HTML-прототипу. Збереження, які вже існують у браузері, не переносяться автоматично в застосунок.
- Наявність доступу до інтернету в Android-проєкті не означає, що онлайн-арена вже реалізована. Для справжніх PvP-боїв, облікових записів і синхронізації потрібен сервер/API та захист від підміни результатів на клієнті.
- Пакет застосунку: `ua.tiniareni.game`. Якщо пізніше планується публікація, цей ID треба зберегти.
- Не додавай паролі, ключі підпису чи секретні токени до публічного репозиторію.
